# Speak Swift

главная страница без адаптива
далее создатся окно окно обратной связи и адаптив
## Требования

Перед запуском установите:

- **Node.js** (версия 14.0.0 или выше)
- **npm** (обычно устанавливается вместе с Node.js)

## Инструкция по запуску

### 1. Клонирование репозитория с GitHub
### 2. Установка зависимостей

```bash
npm install
```

### 3. Запуск приложения

```bash
npm start
```

После выполнения этой команды:
- Приложение автоматически откроется в браузере по адресу `http://localhost:3000`
- Если браузер не открылся автоматически, откройте его вручную и перейдите по адресу `http://localhost:3000`
- Приложение будет автоматически перезагружаться при изменении кода

### 4. Остановка приложения

Для остановки сервера разработки нажмите `Ctrl + C` в терминале.
